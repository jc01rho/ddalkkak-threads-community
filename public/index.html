스마트 에디터

Threads에 올릴 일반 글 6개를 만드는 두 가지 방법입니다. 둘 다 생성이 끝나면 초안함으로 이동해 검수·수정·승인할 수 있습니다.

자동으로 자료 골라 6개 만들기

등록된 자료 중에서 딸깍이 자동으로 골라 글 6개를 한 번에 만듭니다. 직접 고르는 과정이 없어 가장 간편한 방법입니다.

자료를 직접 선택해서 만들기

자료 수집 화면의 "자료 후보 검수" 목록에서 원하는 자료를 직접 골라 그 자료로 글을 만듭니다.

제휴 상품 정보를 직접 입력하면, 사진·영상 없이도 Threads에 올릴 수 있는 홍보 문구 6개를 만들어 초안함으로 보냅니다. 이 화면은 제휴처 API 연동이나 상품 페이지 자동 수집·이미지/영상 다운로드를 하지 않으며, 아래에 직접 입력한 내용만 근거로 작성됩니다.

예약 관리

자동배치 시간표

매일 반복할 예약 시간을 등록해두면, "승인 글 자동배치"에서 승인된 글들을 이 시간표에 맞춰 자동으로 배치할 수 있습니다.

설정한 시간표는 승인 글을 자동으로 배치할 때 사용됩니다. 실제 발행 예정 시간은 예약 목록에서 확인하세요.

승인 글 자동배치

승인(approved) 상태의 글만 선택할 수 있습니다. 선택한 순서(기본: 생성 시각이 오래된 글부터)대로 위 시간표의 빈 슬롯에 배치됩니다.

자동배치 미리보기

아직 저장되지 않았습니다. 아래 배치를 확인한 뒤 "예약 확정"을 눌러야 실제로 예약됩니다.

성과(조회수 등) 조회 기능은 v1에서 아직 지원하지 않습니다. (추후 지원 예정)
